Simple flow: Brightspace to Learning Hub to Supabase

Brightspace remains the course and learner-auth system of record. The Learning Hub reads selected Brightspace data through secure server-side API routes, then stores the pieces we need for the Learning Hub experience in the shared Supabase project. Supabase Auth is reserved for Brightspace Manager staff/admin access.

  1. Brightspace

    System of record

    Courses, modules, topics, enrollments, completion rules, and learner activity that Brightspace already manages.

  2. Learning Hub

    Experience layer

    Our custom front end and API layer. Learner sign-in should come through Brightspace; the Hub requests approved Brightspace data and presents learner, manager, and program/reporting views.

  3. Supabase

    Custom data layer

    Shared project for Learning Hub and Brightspace Manager data: synced catalog records, search behavior, feedback, future reporting support, and Manager staff/admin auth.

Current proof: OAuth works and Brightspace course/content reads work. Validation focuses on syncing Course 6703 metadata into learning_items with production-ready terminology and route hardening.

Brightspace API integration decisions

Outcome: API Integration Decisions confirms Brightspace as the system of record and the Learning Hub as the learner-facing discovery layer.

Service user

Auth model

  • Dedicated Brightspace service account
  • Role assigned high enough for org unit inheritance
  • Scopes narrowed before production

APIs plus Data Hub

Data source split

  • APIs for learner-facing search and content structure
  • Data Hub for initial load and reporting
  • Store Brightspace IDs in Supabase

Bulk load, then refresh

Sync model

  • Nightly catalog/course/module reconciliation
  • More frequent sync only for awards or completion if needed
  • Archive or hide locally instead of hard-deleting courses

LACE Learning Hub — one app, role-based views

Dashboards are built into LACE Learning Hub, not as separate Brightspace, Supabase, or Monday products. A single API layer merges Brightspace + Supabase; each user sees only their role's screens.
